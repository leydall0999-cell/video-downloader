# 网页版下载功能 · 全平台实测报告

> 测试时间：2026-08-24 ｜ 测试对象：网页版下载解析管线（`downloader.probe`，与线上同一套代码）
> 测试方式：本地直接调用解析函数 + 尝试直连生产 API

## 一、先看两个环境限制（决定本轮能测到什么）

1. **Cloudflare 对沙盒出口 IP 的 POST 拦截**：高频/并发请求 `/api/resolve` 会触发 Cloudflare Error 1010（IP 被站点防火墙封禁）。单发低速请求可通，但无法批量打生产接口。→ 国际平台无法从本环境批量验证。
2. **沙盒出网代理对国际站点返回 502**：本地 `yt-dlp` 请求走沙盒代理，国际站点（YouTube/Vimeo/TikTok…）代理返回 `Tunnel connection failed: 502`。**这不代表网页版表现**——生产环境 Railway 直连这些站点，连通性正常。

因此本轮**可靠结论**来自：①本地直接调用解析代码（对代理可达的国内站点真实有效）；②单发低速生产请求抽样（YouTube 实测成功）。

## 三、真实代码级问题（可复现，与测试链接无关）

### A. 域名映射错误 → 已修复并部署 ✅（commit `a817cdf`）
用户粘贴**有效链接**却误报"不在支持列表"，因为目录里注册的域名和实际站点域名不一致：

| 平台 | 原注册域名 | 真实域名 | 影响 |
|---|---|---|---|
| 咪咕 migu | `miguvideo.com` | `music.migu.cn` / `migu.cn` | 粘真实链接报"不支持" |
| 华数TV wasu | `wasu.com.cn` | `wasu.cn` | 同上（且 `wasu.cn` 还被误列进 NON_VIDEO_HOSTS） |
| 淘宝直播 taolive | `taolive.taobao.com` | `hudong.taobao.com` | 同上 |
| KinoPoisk | `kinopoisk.ru` | `hd.kinopoisk.ru` | 同上 |

已修复并推送 web-dev，Railway 已自动部署。本地已校验这四个域名现在能正确识别。

### B. 收录但"无解析器"（需开发提取器）
粘链接报"该平台已收录，但暂未实现该站的解析器"：

- **土豆 tudou**、**微视 weishi**、**网易云音乐 netease**、**YY直播 yy**、**Disney+ Hotstar**、**KinoPoisk**
- 这些在平台列表里展示，但 yt-dlp 无对应提取器、VDL 也未自研 → 实际不可用。

### C. 优酷 youku 需播放签名 ckey
优酷解析需要前端实时计算的 `ckey`（约 40 分钟时效）。网页端没有桌面端 Playwright 拦截能力，无法注入 ckey → 解析失败。需桌面端兜底或后续补云端 ckey 服务。

### D. 依赖远程 VPS 解析服务的 9 个平台（生产可用性待确认）
douyin、kuaishou、weibo、xigua、iqiyi、yangshipin、funshion、movie1905、bestv
这些平台解析依赖远程节点（`VDL_COOKIE_REFILL_TOKEN`）。沙盒未配置该 token → 报"视频解析服务未配置"。**生产环境能否使用，取决于 Railway 是否设置了该 token**——本环境无法确认，需在网页版实粘这几个高频链接验证。
