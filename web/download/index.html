macOS

DMG · 291 MB · macOS 11+（Intel / Apple Silicon 通用版）。

下载 macOS

安装：打开下载的 DMG，把「视频工坊」拖进「应用程序」文件夹。首次打开若提示无法验证，请右键点按图标再选「打开」（仅需一次）。

打不开 DMG？下载 ZIP 版（269 MB，解压后同样拖进「应用程序」）

下载太慢？点这里提速
安装包由 Cloudflare 全球边缘分发，支持断点续传。网络不佳时用多线程下载工具通常能快 2–4 倍：

· aria2（命令行）：先 brew install aria2，再运行 aria2c -x16 -s16 "https://hanyuxz.top/download/installer?p=macos"

· FDM / Motrix（免费图形工具）：新建任务，粘贴本页「下载」按钮的链接即可

Windows

安装程序 · Windows 10 / 11（64 位）。

下载 Windows

安装：双击 Setup 程序按提示完成；若 SmartScreen 提示「Windows 保护了你的电脑」，点「更多信息 → 仍要运行」即可（新发布软件常见提示）。

种子（磁力）下载即将支持；语音识别模型将在首次使用本地字幕时自动下载。

浏览器扩展

Chrome / Edge 专用。在网页里嗅探视频 / 音频，一键发回「视频工坊」下载（需配合桌面客户端使用）。

下载扩展安装包

安装：下载解压 → 打开 chrome://extensions → 开启「开发者模式」→ 点「加载已解压的扩展程序」选解压后的文件夹

安装包由 Cloudflare 全球边缘网络分发，下载即最新版；后续版本可在客户端内一键更新（增量补丁，通常只有几 MB）。安装包已不含语音识别模型——首次使用本地字幕/识别功能时会自动下载该模型（146 MB，同样走全速边缘，有进度显示，可跳过不用）。
