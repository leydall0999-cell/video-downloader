    下载说明

    使用方法

    1. 把视频播放页链接粘贴到上方输入框（首页 / 列表页不行）。
    2. 点「解析链接」，自动识别标题、时长与可选清晰度。
    3. 选好画质后点「开始下载」，进度条与速度实时更新。
    4. 完成后点任务卡片上的「保存文件」即可取回本地。

    已知限制

    • 会员 / 付费视频：如腾讯部分分集，受版权保护无法解析，约 20 秒内会明确提示。
    • 爱奇艺等部分平台受上游提取器限制，可能解析失败。
    • 直播内容暂不支持下载；非视频站点（如搜索引擎）会被直接拦截。
